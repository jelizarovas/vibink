# Vibink logo exploration — 2026-08-08

These files preserve the early material-style V, quill, and fountain-pen logo directions reviewed while Vibink was being established as a standalone product.

The canonical extension asset is [`extension/vibink-mark.svg`](../../../../extension/vibink-mark.svg). At relocation time, `vibink-material-fountain-v.svg` in this folder was byte-identical to that production mark. The other files are concept history and are not included in the Chrome package.
