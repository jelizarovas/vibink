# Vibink 2.0 release

Released September 7, 2026, Pacific time. GitHub records publication on September 8 UTC.

## Release record

- Version: `2.0.0`.
- Source: [pull request #3](https://github.com/jelizarovas/vibink/pull/3), merged after passing CI.
- Release commit: `2d0882338a8820080ef6c00c58a70aa1697f28ff`.
- Tag and assets: [GitHub release v2.0.0](https://github.com/jelizarovas/vibink/releases/tag/v2.0.0).
- Download and setup were initially distributed through an owner-only page.
- Distribution: developer release installed as an unpacked Chrome extension. No Chrome Web Store publication.

The owner-only page was deployed successfully. Its release copy used plain setup and update steps.

## What shipped

- Request snapshots bind the selected component, marks, and draft to an explicit request. Codex reports actual progress; stale feedback for an older request is rejected.
- The local task picker discovers bridges on the same computer. Switching tasks revokes the previous authenticated session before connecting to another. Manual LAN pairing remains available.
- Selection follows scrolling and uniquely identified component replacements. Ambiguous replacements ask for reselection. Spatial feedback and requests clear when their page context becomes stale.
- Original and Preview compare available temporary drafts. Keep, Request changes, and Revert source send owner intent to Codex; those buttons do not execute source changes.
- Finished strokes use a bounded drawing cache. A closed-shadow event-routing bug that could discard canvas clicks was fixed.
- The earlier 0.1.6 responsiveness work is included: feedback revisions and long polling, fewer repeated updates, correct end-of-drawing state, and tolerance for transient connection failures.

Voice stays in Codex. Request status changes require Codex to retrieve and acknowledge the request; the bridge does not wake a task or inject a voice turn.

## Verification

- All 135 Node tests passed. Static checks, extension packaging checks, and release pull-request CI passed.
- All 11 isolated Chromium checks passed, including 200 strokes, request progress, CSS comparison, owner intent, scrolling, component replacement, and restricted-page rejection. No page or console errors remained.
- The final synthetic browser run measured rendering at 0.5 ms at the 95th percentile over the latest 120 samples. This is an automated browser measurement, not a physical pen latency result.
- ZIPs downloaded from GitHub and the owner-only page matched the locally verified release byte for byte. The published checksum matched; anonymous access to the owner-only page was rejected.

## Updating

Replace the extracted extension files, reload Vibink in Chrome, and refresh the target page. Update the local bridge checkout and start a fresh Codex task before reconnecting; an existing task keeps its old bridge process.
