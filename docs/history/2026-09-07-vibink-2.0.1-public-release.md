# Vibink 2.0.1 public release

Vibink 2.0.1 prepared the existing repository for public use.

## Public release changes

- Replaced the fixed development PIN with a random six-digit code that expires after five minutes and rotates after a successful connection.
- Kept failed-pairing attempt limits intact when Codex displays the connection details again.
- Added request, header, idle-socket, per-socket, and connection limits to the optional LAN bridge.
- Changed the extension's built-in bridge address to loopback and removed the machine-specific LAN host permission and setup copy.
- Added an MIT license.
- Added a Codex plugin manifest containing the reusable Vibink workflow skill. The skill can be installed from its public GitHub folder. The local MCP bridge still requires the user's own Chrome extension ID through the guarded registration script.
- Added a static GitHub Pages download and setup page under `docs/`.

Download and setup: https://jelizarovas.github.io/vibink/

## Privacy review

The current release tree contains no stored extension ID, pairing credential, API key, service-account file, browser capture, diagnostic payload, or private download-page account data. The repository keeps its existing commit history; earlier commits contain development-only private-network defaults and the repository author's commit metadata.

## Verification

Static checks, all 138 Node tests, extension build, exact ZIP verification, plugin contract checks, and the isolated browser smoke test passed before publication. Pull-request CI and GitHub release provenance checks gate the published tag and assets. Live Surface Hub hardware, a physical pen, Chrome Web Store publication, native Codex voice behavior, and HTTPS injection through Chrome's real toolbar gesture were not tested for this release.
