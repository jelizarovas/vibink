Windows or another Node.js 22 host, Chrome or Chromium, and Codex.

01

Install the extension

Extract the ZIP, open chrome://extensions, enable Developer mode, and load the extracted folder.

02

Register the bridge

Clone the repository, copy the extension ID from Chrome, and run the guarded PowerShell setup command in the README.

03

Connect a task

Ask Codex to connect Vibink. Enter the six-digit PIN it reports, then click Vibink on the page you want to work on.

Codex skill included

Install the workflow skill

The repository contains the Vibink workflow skill inside its plugin package. Ask Codex's skill installer to install the public GitHub folder, then start a new Codex task.

What changed

2.0.1 is ready for public use

  • Pairing now uses a random six-digit PIN that expires after five minutes and rotates after use.
  • The extension starts on loopback. A LAN address requires an explicit Chrome permission and --allow-lan.
  • The repository ships a Codex plugin manifest, an installable workflow skill, and an MIT license.
  • Request progress, visual comparison, and owner review stay tied to the current page context.

Local by design

The bridge stays on your machine.

Vibink has no account, hosted relay, analytics service, or voice recorder. It does not read cookies, passwords, browser storage, or form values into Codex context. Screenshots and diagnostics require separate actions.
